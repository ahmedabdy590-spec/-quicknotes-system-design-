# QuickNotes API Design

This document describes the production QuickNotes API. The browser exercise uses JSONPlaceholder as a practice service; the endpoints below are the API the QuickNotes backend should implement.

Base URL: `https://api.quicknotes.example/v1`

All requests and responses use JSON unless a response body is omitted. Authenticated endpoints require a bearer token in the `Authorization` header.

## Endpoints

| Method | Path                           | Description                                                             | Success status |
| ------ | ------------------------------ | ----------------------------------------------------------------------- | -------------: |
| POST   | `/auth/register`               | Register a user account.                                                |    201 Created |
| POST   | `/auth/login`                  | Authenticate a user and issue an access token.                          |         200 OK |
| GET    | `/notes`                       | List the authenticated user's notes; supports pagination and filtering. |         200 OK |
| POST   | `/notes`                       | Create a note for the authenticated user.                               |    201 Created |
| GET    | `/notes/{noteId}`              | Retrieve one of the authenticated user's notes.                         |         200 OK |
| PATCH  | `/notes/{noteId}`              | Update selected fields of a note.                                       |         200 OK |
| DELETE | `/notes/{noteId}`              | Delete a note owned by the authenticated user.                          | 204 No Content |
| PUT    | `/notes/{noteId}/tags/{tagId}` | Attach a tag to a note.                                                 | 204 No Content |
| DELETE | `/notes/{noteId}/tags/{tagId}` | Remove a tag from a note.                                               | 204 No Content |

## Create a note

Request:

```http
POST /v1/notes
Authorization: Bearer <access-token>
Content-Type: application/json
```

```http
{
  "title": "Plan weekend trip",
  "body": "Book a train and choose a hotel."
}
```

Response:

```http
201 Created
Content-Type: application/json

{
  "id": "note_01JABC123",
  "userId": "user_01JXYZ456",
  "title": "Plan weekend trip",
  "body": "Book a train and choose a hotel.",
  "createdAt": "2026-10-24T10:30:00Z",
  "updatedAt": "2026-10-24T10:30:00Z",
  "tags": []
}
```

Notes:

- `id`, `userId`, `createdAt`, and `updatedAt` are generated by the server.
- The `tags` array contains identifiers of tags attached to the note.
